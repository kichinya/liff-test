▶ 清掃を始めるとき・終わったとき

いちばん大事な操作です。この2つで実働時間が記録され、業務委託費の元になります。

  1. 現場に着いたら、LINEの下のメニューにある 開始 を押します
  2. その日の物件が出るので、これから入る物件を選びます（1件だけの日は自動で選ばれます）
  3. 終わったら 完了 を押します
⚠️ 開始を押し忘れたまま完了はできません。「完了できる清掃が見つかりませんでした」と出たら、先に開始を押してください。
すでに開始した物件でもう一度開始を押すと「すでに開始を報告済みです」と出ます。二重に記録されることはありません。
🔁 1日で終わらなかったとき
完了を押すと 「作業は終わりましたか？」と聞かれます。
・✅ 終わりました … その日で完了。清掃後の写真をお願いします
・🔁 続きがあります … 次に 開始 を押したとき、 この清掃が候補に出ます。そのまま再開してください
その日ぶんの実働時間は、どちらを選んでも記録されています。
📷 開始と完了のあとに、写真のお願いが出ます。 清掃前・清掃後の写真は全物件で必要です。出てきたリンクをタップして送ってください。 くわしくは下の 📷 写真報告 をご覧ください。
⏱ 予定より15分以上超過すると、完了のメッセージに超過分が出ます。 そのときは理由を超過報告からお知らせください。オーナー様へ共有させていただきます。
時間どおりに終わった回には出ません。

備品の不足・立替・申し送りは、案内が出ていなくてもメニューの 報告 からいつでも出せます。忘れないうちにその場でお願いします。
🧹 清掃とチェックの選び分け

同じ物件に「清掃で入る」場合と「チェックだけで入る」場合があります。

その日の担当に入っていない物件を選んだときや、すでに完了を出した物件をもう一度選んだときに、🧹 清掃 と 🔍 チェック のどちらかを聞かれます。実際に行う作業のほうを選んでください。

担当に入っている物件をふつうに開始する場合は、聞かれません。そのまま進めて大丈夫です。

📷 写真報告
📷 2026年8月5日から、すべての物件で 清掃前・清掃後 の写真をお願いしています。
オーナー様に清掃の状態をご確認いただくためのものです。お名前は出ません。

いちばん簡単なのは、開始と完了のあとにそのまま送る方法です。

  1. 現場に着いて 開始 を押す
  2. 「清掃前の写真をお願いします」と出るので、そのリンクをタップ
  3. 物件と区分を確かめて 📷 写真を送る を押す
  4. このトークに写真を送る（アルバムからまとめて選べます・枚数の制限はありません）
  5. 終わって 完了 を押し、同じように清掃後の写真を送る

あとから送るときは、報告 を開いて 📷 写真報告 を選び、 清掃日と物件、清掃前 か 清掃後 を選んでください。

🔧 破損・故障・汚損を見つけたときは、引き継ぎにも残してください
写真だけだとフォルダに溜まるだけで、こちらから気づけないことがあります。 報告 の中の 📝 引き継ぎ に一言書いてください。 写真報告の画面にも 📝 引き継ぎを書く のボタンがあります。
写真は先に送ってからお願いします。
🔁 あとから追加で送れます
同じ物件・同じ区分でも何度でも送れます。先に送った写真が消えることはありません。
清掃前の写真を送ったあとに破損を見つけたときは、そのぶんだけ追加で送ってください。 撮り直して全部送り直す必要はありません。
🖼 撮っていただきたいもの
・清掃前 … 汚れや傷みが分かるところ
・清掃後 … お部屋ごとの全体（寝室／リビング／水まわり／玄関）
きれいに仕上げていただいた状態が伝わればじゅうぶんです。枚数を競うものではありません。

その場で撮っても、すでに撮ってある写真を選んでも大丈夫です。写真は自動で縮小してから送られます。

🕒 あとから送っても大丈夫です
清掃日を選べるので、直近7日ぶんはいつでも送れます。 その場で送れなかったときは、落ち着いてからで構いません。
ただし撮影はその場でお願いします。あとから撮り直すことはできません。
📱 写真は「このトークに送る」だけです
📷 写真を送る を押すと受付が始まり、画面が閉じます。 あとはこのトークに写真を送るだけです。 アルバムからまとめて選べるので、何枚でも数タップで送れます。
枚数の制限はありません。1枚でも何十枚でも同じ送りかたです。

送り終わったら、そのままで大丈夫です。最後の写真から10分ほどで自動的に締めて、 清掃前・清掃後それぞれの枚数をお知らせします。
次の物件を送るときは、待たなくて大丈夫です。 もう一度 📷 写真報告 から選び直せば、 ここまでの分は自動で締めて、枚数をお知らせします。
📷 「写真を読み込めませんでした」と出たとき
iPhoneの写真は、そのままでは読み込めないことがあります。 その写真を写真アプリで開いてスクリーンショットを撮り、そのスクショを選んでください。それなら確実に送れます。
読めた写真だけは送られます。何枚届いたかは画面に出ますので、足りない分だけ送り直してください。

⏱ 超過報告・📦 備品発注・📝 引き継ぎ

清掃中に起きたことを、文章で残せます。物件を選んで内容を書くだけです。

  • ⏱ 超過報告 … 想定より時間がかかったとき（例: 鍵のトラブルで30分超過）
  • 📦 備品発注 … 消耗品が足りないとき（例: トイレットペーパー残り1個）

↩️ 間違えて報告したとき

報告 の中の ↩️ 報告の取消 から取り消せます。その日にご自分が出した報告が一覧で出るので、取り消したいものを選んでください。

取り消したあと、正しい内容でもう一度報告してください。

⚠️ 取り消してから開始を押し直すと、開始時刻が押し直した時刻になります。実際に始めた時刻と違う場合は、下の「⏰ 打刻の後入れ」で直せます。
⏰ 開始や完了を押し忘れたとき

あとから入力できます。報告 の中の ⏰ 打刻の後入れ を選んでください。

  1. 清掃日 を選びます
  2. 入力が必要な物件が出るので、選びます
  3. 実際に作業した日 を選びます（清掃日と同じならそのままで大丈夫です）
  4. 実際の 開始時刻 と 完了時刻 を入れます
  5. 🧹清掃 か 🔍チェック を選んで記録します

すでに記録済みの清掃も選べます。物件名の横に ✔ 10:03〜13:02 記録済み のように出ます。

🔁 一度終えた清掃に、あとから入り直したとき
「昼に清掃 → ゲスト様のご都合で中断 → 夜に仕上げ」のような場合も、 2回目の時間をここから出してください。その日のうちなら 開始 を押し直すだけでも記録できます。
前回と時間が重なっていると記録できません（同じ作業が二重に入るのを防ぐためです）。
翌日にまたがった場合は「実際に作業した日」で翌日を選んでください。 日が違えば、同じ時間帯でも記録できます。
⚠️ 実際に作業した時刻を入れてください。業務委託費のもとになる記録です。入力すると管理側にも通知されます。

日をまたいだ場合と、締切を過ぎた月の分は入力できません。その場合はこのトークにそのままご返信ください。

🙋 清掃希望を出す・挙手する

LINEの下のメニューにある 清掃希望を送信 を押すと、画面の上に3つのタブがあります。

  • 清掃希望日 … 入れる日をカレンダーで選んで送ります
  • 挙手する … 募集中の案件に手を挙げます。希望の開始時刻も出せます（「おまかせ」でも大丈夫です）
  • マイ予定 … 担当が決まった予定を見る・直す・辞退する

希望の開始時刻を出した案件は、こちらの都合で勝手に動かしません。「おまかせ」で出した案件は、回りやすいように時間を調整させていただくことがあります。

⚙️ 移動手段・出発地の設定

前日にお送りする地図の経路を、より実際に近づけるための設定です。報告 の中の ⚙️ 移動手段・出発地 から変えられます。

  • 移動手段 … 徒歩／自転車／バイク／車／電車・バス（あてはまるものを全部）
  • 出発地 … 番地までは不要です。町名まで、または最寄り駅で大丈夫です

経路の計算だけに使います。どちらも空欄のままで問題ありません。

聞きたいことがあるとき
