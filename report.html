⏰ 打刻の後入れ

開始や完了を押し忘れた清掃を、あとから入力できます。

実際に作業した時刻を入れてください。
入力すると管理側にも通知されます。業務委託費のもとになる記録です。
日をまたいだ場合は、清掃スタッフグループへご連絡ください。

❓ 使い方

知りたいところをタップすると開きます。
分からないときは、遠慮なく清掃スタッフグループへお尋ねください🙇

▶ 清掃を始めるとき・終わったとき

いちばん大事な操作です。この2つで実働時間が記録され、業務委託費の元になります。

  1. 現場に着いたら、下のメニューの 開始 を押します
  2. その日の物件が出るので、これから入る物件を選びます（1件だけの日は自動で選ばれます）
  3. 終わったら 完了 を押します
⚠️ 開始を押し忘れたまま完了はできません。「完了できる清掃が見つかりませんでした」と出たら、先に開始を押してください。
すでに開始した物件でもう一度開始を押すと「すでに開始を報告済みです」と出ます。二重に記録されることはありません。
🧹 清掃とチェックの選び分け

同じ物件に「清掃で入る」場合と「チェックだけで入る」場合があります。

その日の担当に入っていない物件を選んだときや、すでに完了を出した物件をもう一度選んだときに、🧹 清掃 と 🔍 チェック のどちらかを聞かれます。実際に行う作業のほうを選んでください。

担当に入っている物件をふつうに開始する場合は、聞かれません。そのまま進めて大丈夫です。

📷 写真報告

清掃の前後の写真を残せます。

  1. メニューの 📷 写真報告 を選びます
  2. 物件と、清掃前 か 清掃後 を選びます
  3. 写真を選んで送信します（最大6枚）

その場で撮っても、すでに撮ってある写真を選んでも大丈夫です。写真は自動で縮小してから送られます。

💰 立替精算

備品などを立て替えて買ったときに出してください。

  1. メニューの 💰 立替精算 を選びます
  2. 清掃日 を選びます（数日前の分も出せます）
  3. その日の物件から、対象の物件を選びます
  4. 金額と用途を入れます
  5. 領収書の写真を選びます（最大4枚・任意）
⚠️ 締切は毎月1日です。前の月の分は1日までに出してください。締切を過ぎた月の清掃日は選べなくなります。
間に合わなかった場合は、清掃スタッフグループへご連絡ください。
⏱ 超過報告・📦 備品発注・📝 引き継ぎ

清掃中に起きたことを、文章で残せます。物件を選んで内容を書くだけです。

  • ⏱ 超過報告 … 想定より時間がかかったとき（例: 鍵のトラブルで30分超過）
  • 📦 備品発注 … 消耗品が足りないとき（例: トイレットペーパー残り1個）
  • 📝 引き継ぎ … 次に入る人に伝えたいとき（例: エアコンの効きが悪い）

送ると管理側にも通知が届きます。返事が必要なものは、担当から改めてご連絡します。

↩️ 間違えて報告したとき

メニューの ↩️ 報告の取消 から取り消せます。その日にご自分が出した報告が一覧で出るので、取り消したいものを選んでください。

取り消したあと、正しい内容でもう一度報告してください。

⚠️ 取り消してから開始を押し直すと、開始時刻が押し直した時刻になります。実際に始めた時刻と違う場合は、清掃スタッフグループへお知らせください。
📅 自分の予定を見る

見かたは3つあります。

  • 毎日18時ごろのLINE … 翌日の予定が届きます。順番どおりに回れる地図のリンク付きです
  • 📅 マイカレンダー … スマホのカレンダーアプリで見られます
  • 清掃希望を送信 →【マイ予定】 … 先の予定まで一覧で見られます
📋 順番や時間を変えたいとき

リッチメニューの 清掃希望を送信 を押して、上の マイ予定 タブを開いてください。

  • ▲▼ で回る順番を入れ替えられます（時刻は自動で詰め直します）
  • 開始時刻もプルダウンで選び直せます
  • ✨ おすすめの順番 を押すと、回れる並びが入ります

最後に この日の予定を保存する を押してください。

⚠️ 回れない並び（時間が重なる・チェックアウト前に始まる・次のお客様のチェックインに間に合わない）は保存できません。理由が赤い字で出るので、直してから保存してください。安心して触ってみてください。

🔒 2人で入る予定と、すでに開始を報告した予定は変えられません。清掃スタッフグループへご連絡ください。
🙋 清掃希望を出す・挙手する

リッチメニューの 清掃希望を送信 に3つのタブがあります。

  • 清掃希望日 … 入れる日をカレンダーで選んで送ります
  • 挙手する … 募集中の案件に手を挙げます。希望の開始時刻も出せます（「おまかせ」でも大丈夫です）
  • マイ予定 … 担当が決まった予定を見る・直す

希望の開始時刻を出した案件は、こちらの都合で勝手に動かしません。「おまかせ」で出した案件は、回りやすいように時間を調整させていただくことがあります。

⚙️ 移動手段・出発地の設定

前日にお送りする地図の経路を、より実際に近づけるための設定です。メニューの ⚙️ 移動手段・出発地 から変えられます。

  • 移動手段 … 徒歩／自転車／バイク／車／電車・バス（あてはまるものを全部）
  • 出発地 … 番地までは不要です。町名まで、または最寄り駅で大丈夫です

経路の計算だけに使います。どちらも空欄のままで問題ありません。

🏠 対応できる物件を変えたいとき

メニューの 🏠 対応できる物件 から、ご自分で更新できます。ここで外した物件は、募集のお知らせが届かなくなります。

「この物件はもう入れない」「このエリアなら入れる」といった変更は、ご自分で直していただいて構いません。

😥 うまくいかないとき

画面が開かない・古いままのとき
LINEアプリをいったん完全に終了して、開き直してください。それでも直らないときはご連絡ください。

送信したのに反映されていないとき
送信できたときは、必ずLINEに確認のメッセージが届きます。届いていなければ受け付けられていません。電波の良い場所でもう一度お試しください。

物件が出てこないとき
その日の担当に入っていない可能性があります。清掃スタッフグループへご連絡ください。

困ったときは、無理に操作せず清掃スタッフグループへご連絡ください。あとから管理側で直せます🙇
